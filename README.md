# 🔧 Бот учёта инструментов — Установка на Railway

## Что нужно сделать на Railway

### 1. Добавить PostgreSQL к проекту

В твоём Railway-проекте:
1. Нажми **+ New** → **Database** → **Add PostgreSQL**
2. Railway автоматически создаст переменную `DATABASE_URL` для всех сервисов проекта

### 2. Подключить переменную окружения к боту

В сервисе бота (твой Python-сервис):
1. Открой вкладку **Variables**
2. Добавь переменные:
   - `BOT_TOKEN` — токен бота от @BotFather (уже есть)
   - `DATABASE_URL` — нажми **Add Reference** → выбери Postgres → `DATABASE_URL`
   - `INITIAL_ADMIN_ID` — твой Telegram ID (узнать у @userinfobot)

### 3. Залить новые файлы

Файлы которые нужно загрузить в репозиторий:
- `bot.py` (новый, с поддержкой БД)
- `database.py` (новый модуль работы с БД)
- `schema.sql` (схема таблиц)
- `requirements.txt` (обновлённый, с psycopg2)

### 4. Деплой

Railway сам перезапустит бот после пуша в GitHub.

При первом запуске:
- Бот сам создаст таблицы в БД (`init_db()`)
- Создаст начального админа из `INITIAL_ADMIN_ID`
- Ты сможешь зайти в бот командой `/start` и начать добавлять пользователей и категории

---

## Как пользоваться

### Первые шаги (для админа):

1. **`/start`** — авторизация (тебя авто-зарегистрирует как админа)
2. **🗂 Управление категориями** → добавь категории (болгарки, перфораторы и т.д.)
3. **👥 Управление пользователями** → добавь сотрудников (нужен их Telegram ID)
4. **➕ Добавить инструмент** → создай инструменты, привязав к категориям и владельцам

### Как сотруднику пользоваться:

1. Сотрудник запускает бот командой `/start`
2. Если он добавлен админом — получит доступ
3. Может смотреть инструменты, передавать свои инструменты другим, видеть историю

### Передача с подтверждением:

1. Владелец выбирает инструмент → **🔄 Передать** → выбирает получателя
2. Получателю **приходит уведомление** с кнопками "Подтвердить / Отказать"
3. Только после подтверждения инструмент переходит к новому владельцу
4. Отправитель получает уведомление о результате
